# OpenSat Mission Lab v1.5.0

v1.5 introduces an explainable onboard-autonomy and edge-intelligence demonstration.

## Highlights

- Deterministic scene-feature and image-quality surrogates
- Explainable flood-event probability
- Resource-aware downlink, defer, discard, and review actions
- Autonomous target reprioritization
- Conflict-checked autonomous constellation tasking
- Edge-compute latency and energy profile
- Interactive autonomy dashboard
- Four new executable acceptance requirements
- Two new unit and regression tests

## Acceptance evidence

The included fast seven-day acceptance profile produced 17 scene assessments, 11 flood triggers, 11 priority-downlink decisions, four reprioritized targets, six selected autonomous tasks, 49/49 passed requirements, 8/8 passed analytical benchmarks, and 91 passed tests.

## Scope

The flood score is a deterministic educational surrogate. It is not trained on imagery and is not an operational flood-detection product.
