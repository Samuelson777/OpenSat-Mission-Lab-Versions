# OpenSat Mission Lab v1.0.0

v1.0 converts the accumulated digital-twin capabilities into a consolidated, portfolio-ready software release with traceable acceptance evidence.

## Added

- Machine-readable requirement catalogue and automated requirement evaluation
- Requirements traceability and verification-result CSV files
- Six analytical benchmark comparisons for orbit, geometry, communications, and ADCS
- Self-contained HTML release-verification report
- Requirement-status and benchmark-margin figures
- SHA-256 manifest for every generated mission artifact
- Verification PASS/FAIL badge
- `opensatlab accept` command that exits nonzero on verification failure
- Windows and Unix one-command acceptance scripts
- Multi-version GitHub Actions CI workflow
- Portfolio case study, five-minute demo script, architecture description, verification plan, and release checklist
- Four verification tests, bringing the suite to 56 tests

## Baseline acceptance result

The bundled seven-day India flood-monitoring scenario passes all automated software requirements and all analytical benchmarks. This result demonstrates deterministic implementation, internal consistency, and reproducible outputs. It does not represent flight qualification, independent certification, or approval to control spacecraft hardware.
