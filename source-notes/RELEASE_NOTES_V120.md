# OpenSat Mission Lab v1.2 Release Notes

Version 1.2 adds a home-lab hardware bridge while preserving the complete v1.1.2
mission, verification, external-comparison, and Orekit workflows.

## Highlights

- OSML-CMD/1 command protocol and OSML-ACK/1 acknowledgement protocol.
- CRC-32 integrity and command-ID correlation.
- Optional pyserial USB/UART telemetry replay, capture, and command exchange.
- Raspberry Pi UDP-to-serial gateway.
- ESP32 Arduino firmware example.
- Automated four-command localhost hardware-bridge validation.
- New hardware reports, tests, VS Code profiles, and setup scripts.
