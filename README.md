# OpenSat Mission Lab — GitHub Pages Website

A dependency-free single-page portfolio website for the complete OpenSat Mission Lab release history, from v0.1.0 through v3.1.0.

## Included

- Interactive replay of the retained seven-day India flood-monitoring mission dataset
- Searchable explorer for all 35 documented releases
- Five engineering-era filters and eight architecture layers
- 27 optimized evidence images generated by the project
- 18 original self-contained HTML dashboards
- Responsive dark/light interface
- Keyboard-accessible dialogs and navigation
- GitHub Pages deployment workflow
- No npm, framework, database, or build step

## Local preview

A local web server is required because the mission replay loads a JSON file.

```powershell
python -m http.server 8000
```

Open:

```text
http://127.0.0.1:8000
```

Opening `index.html` directly still displays most of the site, but browsers may block the JSON telemetry request for local `file://` pages.

## GitHub Pages deployment

### Branch deployment

1. Upload this directory to a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select the default branch and `/ (root)`.
5. Save the configuration.

### Workflow deployment

The included `.github/workflows/pages.yml` workflow can deploy the static directory through GitHub Actions. Enable GitHub Pages with **GitHub Actions** as its source.

## Deploy from an existing OpenSat repository

Copy the contents of this package to `docs/` inside the OpenSat Mission Lab repository. Then configure Pages to deploy the default branch from `/docs`.

The companion integrated archive supplied with this website already contains that structure.

## Customize the project links

The site intentionally avoids a fake repository URL. Add your GitHub profile, repository, release, and contact links directly in `index.html` after publishing the repository.

## Validation

The release package is checked for:

- HTML asset references
- JavaScript syntax
- release-data completeness
- mission JSON parsing
- HTTP serving of the main page, telemetry data, and retained dashboards
- SHA-256 archive integrity

## Scope

OpenSat Mission Lab is educational engineering software. The website does not transmit real spacecraft commands and does not represent flight certification, legal authorization, or operational security accreditation.
